# Дистанційний пілот БПС: відкрита категорія A1/A3

Навчальний сайт українською мовою за структурою курсу «A1/A3 Course & Examination - UAS Remote Pilot Open Category» (DAC Luxembourg, EUROCONTROL Learning Zone). Тексти уроків - авторський виклад, не переклад.

## Структура

- `index.html` - сторінка сайту
- `assets/style.css`, `assets/app.js` - оформлення і рушій (навігація, вправи, прогрес)
- `content/m0.js` - вступ, головна сторінка
- `content/m1.js`, `m2.js`, `m3.js` - уроки модулів і вправи
- `content/tests.js` - тести модулів і підсумковий тест

## Публікація на GitHub Pages

1. Створіть репозиторій і завантажте в нього весь вміст цієї папки.
2. Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save.
3. Через 1-2 хвилини сайт буде доступний за адресою `https://<ваш-логін>.github.io/<назва-репозиторію>/`.

Локально сайт можна відкрити простим подвійним кліком на `index.html`.

## Як редагувати

Кожен урок - об'єкт у `content/m*.js` з полем `html`. Вправи описано в `COURSE.ex`:

- `tf` - дві кнопки (Так/Ні або свої мітки), `a: true/false`;
- `mcq` - вибір однієї відповіді, `correct` - номер правильного варіанта з 0;
- `reveal` - питання з відповіддю, що розкривається;
- `matrix` - таблиця ТАК/НІ.

Вставити вправу в урок: `<div data-ex="ідентифікатор"></div>`. Відео Vimeo: `<div data-video="ID" data-h="хеш" data-cap="Підпис"></div>`.
